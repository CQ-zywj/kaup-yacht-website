## 维护约定

1. 新增能力 → 更新 `功能清单-当前原型.md`，并从 `未实现功能清单.md` 删掉对应条目。
2. 一次性的验收、修复、讨论记录 → 直接放 `archive/`，不要堆在根目录。
3. 截图命名带上模块前缀（如 `console-finance.png`），便于判断归属；被文档引用的截图才保留。
