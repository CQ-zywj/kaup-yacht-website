# 公开供应商列表

首页和通用导航的“供应商”入口改为 `suppliers.html`。首页保留最多四家精选企业，并新增“查看全部供应商”入口。

列表读取已发布商品所属企业，按供应商 ID 汇总，保留本地新增商品的供应商；在售数量按真实商品去重计算，不使用样例企业中预置的数量。卡片展示企业名称、国家、主营行业、演示认证状态和最多三件商品预览。企业名称和“查看供应商产品”打开对应企业的产品列表，预览图片打开商品详情。

支持中英文企业名称搜索、行业筛选、空状态和清除筛选；每页六家，超过六家时自动分页。筛选和页码写入 URL；新搜索重置页码，失效页码收敛到有效范围。公开列表可供访客浏览，供应商工作台权限保持原来的限制。

验证：58 项自动测试通过，覆盖供应商去重、实际数量、双语搜索、行业筛选及分页边界；浏览器检查首页两个入口、企业商品跳转、空状态、语言切换和 375px 手机布局。演示基础数据有四家企业，本地已发布商品可使实际列表更多。
