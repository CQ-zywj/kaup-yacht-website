# 登录状态顶栏与自动跳转

登录成功并保存演示会话后，买家和供应商都直接跳转到 `index.html`，由已有角色逻辑展示对应首页。不再弹出需要点击“继续”的成功对话框；登录时即使带有 return 参数也按本次要求进入首页。注册成功的原有提示及跳转保持不变。

首页不再显示单独的工作导航行。语言、发布按钮与账户卡片保持紧凑排列；买家的询盘入口和供应商的公司、商品、收件箱入口保留在账户下拉菜单中。企业名称过长时省略显示，并保留完整名称的提示。

手机端品牌和语言同一行，发布按钮与账户卡片同一行，搜索单独展示。桌面和手机沿用相同的角色权限。

验证：58 项自动测试通过；浏览器用两类内置演示账户完成实际登录，均自动进入对应首页且无成功对话框。验证买家发布采购、供应商发布供应及各自账户菜单，检查 320px 手机端无横向溢出。最终浏览器保留供应商演示登录状态。
