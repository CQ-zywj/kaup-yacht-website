# 手机布局优化

- 767px 及以下内页导航收起为菜单按钮，展开后以两列展示；按钮提供展开状态与关联导航，Escape 可关闭并返回按钮焦点。桌面继续展示完整导航。
- 首页七个服务入口改成四列、两行网格，避免横向滚动漏看入口。
- 450px 及以下首页精选供应商卡片改成单列，解决 320px 英文链接溢出。
- 供应商列表优化企业名称换行、产品预览高度和触控按钮；分页按钮至少 44px，搜索操作至少 48px。
- 手机表单使用 16px 输入字号，减少移动浏览器聚焦输入时的自动放大；极窄屏菜单采用带无障碍名称的图标按钮。

验证：58 项测试通过；浏览器检查中文 375px、英文 320px 的首页及供应商列表，修复后页面无横向溢出。菜单展开和 Escape 关闭、语言切换已检查；未登录采购页继续显示登录门槛，未修改会话数据。桌面测试使用的临时尺寸覆盖已恢复。
