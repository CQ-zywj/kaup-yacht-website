# 综合产业资讯首页（2026-10-10）

## 用户要求与范围

按用户提供的 ECHEMI 截图调整为顶部搜索和服务导航、左侧类目、中间轮播、右侧快捷采购/供应商询盘。对外展示名称改为北贸汇 / NORTHLINK。移除的是首页独立“船舶与游艇专区”；marine 行业分类、列表、商品详情和 16 条种子商品全部保留。

## 页面与交互

- 首页去掉可见播放/暂停按钮，保留上一张/下一张和指示点。默认间隔 5 秒，自动轮播仍在悬停、轮播链接获得焦点、离屏和减少动态效果时暂停；手动切换后重新计时并继续自动切换；鼠标点击留下的按钮焦点不阻止播放。轮播容器获得焦点时可用空格暂停/恢复；按钮自身的空格键仍正常激活。
- 首页右侧快捷采购收集产品、行业和数量，带入 rfq.html；未登录时登录回跳保留参数，之后回填数量和需求说明。语言切换保留输入。
- 新闻及展会首页模块分别链接 news.html / exhibitions.html；content.html 按 type 和 id 展示标题、内容、日期、展会地点及相关推荐。列表支持关键词搜索和行业分类筛选，未知 id 显示返回入口。
- 新闻为演示编辑稿，展会名称、日期、地点均为演示；页面明确标注。没有发布真实新闻或声称真实展会将举办。
- 供应商首页在轮播下方显示最近 2–3 条原型本地询盘和未读数量，入口带 inquiry 参数在 inbox.html 打开对应详情；浏览器另一个标签页写入询盘或重新聚焦首页时刷新。
- 供应商可查看演示采购线索及 inquiry-detail.html 详情。游客/买家访问该详情需切换供应商；联系演示买家只显示说明，不产生真实通信或假报价。
- 资讯数据集中于 mock/editorial-data.js，页面渲染集中于 js/content.js。保持无构建、无依赖、无后端。

## 验证

- `node --test tests/*.test.cjs`：55 项通过。增加内容数据契约和非法类型查找测试，扩展静态资源检查至四个新增页面。
- 全部 js/*.js 与 mock/editorial-data.js 通过语法检查；git diff --check 无错误。
- 中文首页：播放按钮及 marine-floor 数量均为 0，新闻 3 条、展会 2 条；375px 首页 scrollWidth 等于 clientWidth。
- 英文新闻详情和展会详情可打开；展会日期、地点可见。英文 agricultural 关键词搜索返回对应农产品文章。
- 375px 英文资讯详情无横向溢出；不存在的内容 id 有明确返回入口。
- 快捷采购产品/行业/数量进入 RFQ URL 并经登录提示保留；买家登录后数量 500、需求说明与 bearings 行业正确回填。
- 切换语言时快捷表单三个输入值保留。轮播下一张按钮用空格正常切换。
- 供应商登录：首页实际询盘和演示线索可见，线索详情可打开，联系按钮弹出演示说明。退出后游客不能读取该详情。
- 船舶行业列表仍有现存商品，p01 详情显示“海岚 42 尺飞桥游艇”。未删除原行业或产品数据。
- 测试结束恢复默认视口、中文首页、未登录状态。
