## 0. 一句话结论

原型已从「单行业六页」长成**可完整演示的双边平台**：买家能发现、筛选、比价、成交；供应商能开店、装修、上架、批量导入、接询盘、报价、管证书、写文章、管客户；平台侧有文件存储、证书可见性隔离与机审。

仍然**不是可上线产品**：没有后端、没有真实鉴权、没有文件服务、没有订单与支付、没有运营审核台。这些边界见第 4 节。

## 2. 能力清单

### 2.1 门户与全局

- 顶部：logo、全站搜索、语言切换、主 CTA（买家「发布采购」/ 供应商「发布供应」）、登录注册或账户菜单、未读角标。
- 首页专属：7 项服务导航、搜索范围切换（商品/资讯/展会）、行业导航条、精选商品、精选供应商、资讯与展会。
- 页脚：品牌、6 个行业入口、按角色切换的工作台链接、RFQ 市场入口、语言按钮。
- 搜索：`q` 透传到商品列表并保留语言与筛选参数。

### 2.2 商品发现与筛选

- 6 个一级行业、9 个专业分类（每类 3 子类）、16 件手写商品（船舶四类各 4 件，含 1 件涂装缺项样例）。
- 筛选维度：行业 → 分类 → 子类 → 类目参数（枚举多选、数值区间）→ 供应商 → 认证 → 关键词；不同字段 AND，同字段多选 OR。
- 排序：更新时间 / 相关度（标题精确 > 标题包含 > 全文包含）/ 价格升序；分页 6 条。
- 筛选、排序、页码、语言全部写入 URL，可分享、可刷新还原；已选条件 chip 可单条移除。
- 移动端筛选改为抽屉（遮罩 + `inert` + 焦点陷阱 + Esc）。

### 2.3 商品详情

- 面包屑、主图与缩略图切换、中英标题与描述、价格区间 / MOQ / 交期 / Incoterms / 单位。
- 参数表按类目模板渲染；配件类额外渲染可增删规格键值对。
- 认证区双通道：商品自带的静态认证行（文案弹层）+ 供应商已上传且关联本商品的证书（文件预览）。
- 涂装类合规面板：AFS / VOC / MSDS / UN / 危险等级 / 运输限制，缺项置顶警告。
- 供应商卡：认证状态、在售数、进店、发起询盘。

### 2.4 供应商目录与店铺

- 目录从商品反向聚合去重，统计真实在售数与跨行业标签。
- 店铺主页是对外唯一地址：主题色横幅（ocean/slate/sand）、logo、标语、认证墙、商品橱窗、已发布文章、团队、收藏计数、进店询盘；联系入口只有头部一个按钮，不再重复一张「联系与询盘」卡片。
- 公开公司页：只渲染 `publicProfile()` 白名单字段与有效期内公开证书。

### 2.5 账户、角色与权限（前端模拟）

- 双角色 buyer / supplier，游客可浏览；发询盘、发布、进收件箱、进控制台会被拦截并引导登录。
- 注册校验：必填、邮箱格式、两次密码一致、条款勾选、供应商主营类目至少一项。
- 密码以 **SHA-256 摘要**存 `accounts`（Web Crypto，无盐、无服务端）；重复邮箱拦截。
- 演示账号：`buyer@marinex.demo` / `supplier@marinex.demo`，密码 `Demo123!`，可一键填充。
- 安全回跳：`?return=` 只接受本站 `*.html`；已登录访问登录页直接跳工作台。
- 供应商控制台页面未登录时统一渲染「仅供应商」空状态，不初始化业务逻辑。

### 2.6 买卖沟通（2026-10-29 上线）

- **双模式询盘**：定向询盘（`supplier_id` 指定，自动分配业务员）与公开 RFQ（`supplier_id: null`，进入公开市场）。
- **多轮消息线程**：`messages[]` 保存每一轮，回复不再覆盖；旧单条 `reply` 记录读取时就地升级。
- **报价互不可见**：每家供应商报价时 fork 出以 `public_of` 关联的独立子线程，买家侧聚合比价。
- **结构化报价**：单价、币种、起订量、交期、贸易条款、有效期、说明；校验通过才入库。
- **比价与成交**：横向比价卡，接受后主帖记 `accepted_thread_id`，会话转入中选子线程。
- **未读与已读回执**：每条消息有 `read_at`，自己发出的消息显示已读/未读；导航、页脚、控制台侧栏统一角标。
- **响应时效指标**：未读、待回复、3 天响应率、平均首响。
- **会话生命周期**：`submitted → viewed → replied → quoted → accepted → closed`，关闭后可查看历史，回复会重新打开。
- **通知为模拟**：报价与回复后弹层提示「已邮件通知」，不实际发信。

### 2.7 供应商控制台

- 统一侧栏：**7 组**（总览 / 商品 / 询盘 / 店铺 / 资质 / 内容 / 客户）覆盖 11 个页面，多项组折叠、当前组默认展开，窄屏自动摊平为 11 个 chip；顶部公司名 + 审核徽章 + 询盘未读角标 + 退出。
- 批量导入不再占侧栏一级项：入口在「发布商品」页头与「我的商品」页头，页内有「返回发布商品」。
- 总览：资料完整度四板块评分 + 待办清单 + 最近 5 条询盘 + 商品概览 + 店铺入口。
- 商品：草稿/在售/下架/驳回筛选，上下架切换、删除、预览、继续编辑。
- 发布：提交即机审，通过 `active`、驳回 `rejected`（内容照常落库，不丢已填内容）。

### 2.8 文件与存储

- IndexedDB 数据库 `northlink-supplier-files`：`files` 存 Blob + 元数据，`finance` 存银行资料；页面数据只留 `{id, name, type, size}` 引用。
- 上传校验：按种类限定 MIME 与体积（银行 5MB / 证书 10MB、图片 5MB / logo 2MB / 横幅 3MB / 团队 5MB）；logo ≥400×400，横幅必须 1920×480；SVG 拒绝 `script`/`foreignObject`/`on*`/外部 `href`/`url()`。
- 先全量校验再落库，任一文件不合格则整批不写，避免半成品。

### 2.9 证书、公开投影与团队

- 7 类证书：企业资质、产品证书、检测报告、管理体系、知识产权、其他、授权证书。
- 可见性：`company` / `authorization` 强制私密，不可开关放开；公开证书还需非驳回且落在有效期内。
- 公开投影白名单：不透出邮箱、电话、详细地址、联系人、密码摘要与任何银行字段。
- 团队：控制台维护头像/姓名/职位，公开页只读展示。

### 2.10 客户管理

- 手工建档 + 询盘派生合并去重，按 `company` 升序，支持 6 字段搜索。
- 键为 `customer_profiles:<supplierId>`，与询盘线程解耦；删除为 `hidden` 软删，询盘历史保留。
- 每次读写前校验当前登录供应商标识，防跨账号读写。

### 2.11 内容与文档导入

- 富文本编辑器（`contenteditable` + 轻量工具栏）、封面、分类标签、关联商品（≤6）、定时发布。
- DOCX（mammoth）/ HTML / TXT 导入：先预览，可改标题、替换或追加正文、首图设为封面；确认导入不等于发布。
- 发布前机审：英文标题与正文必填、正文 ≥10 词。

### 2.12 批量导入

- 表格模式：CSV / XLSX / XLS，选工作表，13 列自动映射（支持中文别名），逐行校验，重复导入按 `import_key` 去重，不覆盖已有商品。
- 资料包模式：多文件 / 文件夹 / ZIP，按文件夹把文档与图片成组，逐组编辑校验后批量存草稿。
- 限额：单次 20MB、≤100 个条目（含 ZIP 内条目）。

### 2.13 机审

- 二值判定（通过 / 驳回），规则编号即驳回码，命中第一条即返回，只给用户一个原因。
- 已生效：商品 P01 必填、P02 标题长度、P03 描述长度、P04 价格区间、P09 主图、P16 中英齐全、P17 重复铺货；文章 A01 标题正文、A02 词数；企业 S01 USCC 校验位、S03 公司名占位词；证书 C01 有效期、C03 编号格式、C05 CE 类别；素材 M02 体积。
- 业务停用：P07/A03 联系方式与外链、P08/A04 广告法极限词（逻辑与文案保留，去 `disabled` 即恢复）。
- 其余依赖 OCR / 图像识别 / 工商接口的规则已登记待补，详见 `docs/研发交接-供应商端能力合并-2026-10-29.md` 第 8 节。

### 2.14 双语、响应式与可访问性

- 905 个双语文案键，正文、按钮、枚举、状态、错误、空状态、aria-label、图片 alt 均随语言切换；默认英文，偏好写 `marine_lang`，支持 `?lang=zh`。
- 切换语言保留筛选条件、表单内容与页面参数。
- 响应式 375 / 768 / 1280；控制台桌面优先、窄屏可用。
- 可访问性：跳转主内容、label 关联、`aria-invalid`、`aria-live`、`focus-visible`、`prefers-reduced-motion`、弹层 Esc 与焦点陷阱、键盘轮播与日历。

## 3. 演示路径

**A. 买家主线（10 分钟）**
首页切中文 → 行业「船舶与游艇」→ 筛选「整艇 + FRP + CCS + 12–13 米」→ 排序翻页 → 复制 URL 重开验证条件还原 → 打开涂装商品看 MSDS / 缺项警告 → 点认证徽章 → 进店铺主页 → 发起询盘。

**B. 公开 RFQ 到成交（跨账号，15 分钟）**
买家 `rfq.html?mode=public` 发布需求 → 切供应商 → `rfq-market.html` 报价（填价格/交期/有效期）→ 供应商 `inbox.html` 看四指标与线程 → 切回买家 `my-rfq.html` 比价并接受 → 双方多轮对话 → 观察角标增减。

**C. 供应商开店（15 分钟）**

## 4. 明确边界（当前做不到）

| 能力 | 现状 | 影响 |
| --- | --- | --- |
| 后端与接口 | 完全没有，数据全在浏览器 | 不跨设备、不跨浏览器；无法多人协作演示 |
| 真实鉴权 | 前端模拟，SHA-256 无盐、无服务端校验 | 可被绕过，不能作为安全方案 |
| 文件服务 | IndexedDB 本地 Blob，无病毒扫描、无压缩、无 EXIF 清理 | 换设备即丢；生产必须换对象存储 |
| 交易闭环 | 止于「接受报价」，无订单/合同/支付/物流 | 无法演示真实成交 |
| 运营后台 | 无企业审核台、商品人工复核、举报处理、规则配置 | 审核只能靠机审与「模拟通过」按钮 |
| 机审 | 客户端同步判定，规则与词库在前端 | 可被绕过，正式环境必须服务端重判 |
| 通知 | 无邮件/站内信，仅文案提示 | 双方靠主动刷新发现新消息 |

| 数据统计 | KPI 为演示值，无埋点 | 曝光/访客/转化不可信 |
| 买家工作台 | 只有「我的询盘」 | 无收藏夹、对比、消息中心、采购历史 |
| 数据规模 | 仅船舶 16 件真实感商品，其余 5 行业为空（用于演示空状态） | 只能演示单行业 |
| 深色模式 / 旧浏览器 | 未实现 / 不支持 | — |
