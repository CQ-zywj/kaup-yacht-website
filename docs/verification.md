## 实际响应式尺寸

浏览器 viewport 工具起初未生效，首次宽度读数仍为 1503，该批读数不计为响应式证据。改用当前标签页的开发者尺寸模拟后，DOM 实际 innerWidth 分别为 375、768、1280。

七个页面在三个尺寸下逐一检查，21 组 documentElement.scrollWidth 均等于对应 innerWidth，无整页横向溢出；表单 label 缺失计数均为 0。375 下点击“筛选产品”可以展开并勾选电动动力，正确返回清源 10m 观光艇。桌面首页、手机首页、手机筛选、发布页和询盘详情截图已保存并视觉检查。

截图采集使用 CSS 视口尺寸及当前滚动坐标，修正了浏览器设备像素比例造成的截图裁切问题。临时设备尺寸设置在交付前清除。
