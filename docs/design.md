# 船舶游艇跨境 B2B 静态原型设计

日期：2026-10-08。状态：用户已回复「同意，继续」，设计已确认；进入实施计划阶段。

## 目标与范围

依据用户提供的前端静态原型 PRD v0.3，完成可点击、可演示的买家和供应商原型，验证垂直精准发现、结构化商品发布、询盘收发回复。优先完整实现六个 P0 页面。P1 供应商商品中心在 P0 验收后补充，注册登录为可选模拟页面。无运营后台、审核流程、真实账号、真实邮件或后端接口。

文档提及的 PRD-P0-详细需求.md 和品牌 design-system 未提供，不把这些未读取资料视为已有规范。Product/RFQ 模型使用当前文档可见字段，并在交付说明中记录这一限制。

## 采用方案

推荐纯多页面 HTML/CSS/JS，使用普通 script 加载内置数据，避免模块和 fetch 对本地 file URL 的限制。不引入 React、Vite 或构建工具。页面均可直接打开；另提供本地 HTTP 启动方式，便于多页共享稳定的同源 localStorage 并演示跨标签页询盘同步。首先交付本地原型，静态托管作为后续可选工作。

备选单页哈希路由可以减少公共页面重复，但不如文档列出的六个文件直观；框架方案利于长期开发，但增加本轮不需要的依赖和构建。故使用文档推荐的多页面方案。

## 页面和交互

| 页面 | 核心功能 |
| --- | --- |
| index.html | 品牌、语言切换、全站搜索、价值主张、浏览 CTA、四大类目、六件精选商品、信任条和页脚 |
| products.html | 类目及子类、动态参数、认证多选、数值区间、关键词、排序、分页；筛选同步 URL；空结果可重置 |
| product.html | 中英标题描述、面包屑、主图及缩略图、参数表、证书演示弹层、贸易信息、供应商卡、同类推荐、带商品上下文的询盘入口 |
| publish.html | 中英标题描述、类目模板、本地图片预览、配件规格键值增删、认证添加、贸易字段、草稿恢复、保存草稿及模拟提交 |
| rfq.html | 关联商品或通用需求、买家公司和国家、数量、目标市场、交期、条款、说明和附件占位；校验后写入询盘数组 |
| inbox.html | 未读计数、状态及时间筛选、排序、空状态、完整详情、标记已读、文本及附件占位回复，状态和回复持久化 |

类目：整艇、配件设备、涂装养护、衍生服务。整艇参数包含艇型、材质、长度、动力、航速；配件包含子类、适配艇型、品牌型号及规格；涂装包含 AFS、VOC、MSDS、UN、危险等级和运输限制；服务包含类型、地区和内容。

筛选采用不同条件 AND、同一枚举内多选 OR；数值范围包含端点。切换类目清除旧类目参数，保留通用关键词和认证。URL 恢复筛选和排序；中英切换保留当前上下文。价格排序使用价格下限，更新时间使用日期，相关度使用搜索匹配程度。

涂装详情必须醒目显示合规区；缺少字段明确提示。发布涂装商品时所有指定合规必填项必须通过前端校验；保存未完成草稿允许缺项，但不显示为已提交。MSDS 和证书演示标明为样例，不暗示真实认证。

## 数据与存储

手写 16 件示例商品，每类 4 件，含至少 1 件缺少合规字段的涂装样例。价格、认证和供应商均标明演示数据。数据放在 mock/data.js，同时提供 categories.json 与 products.json 以便替换。媒体使用本地素材或行业主题占位图，不依赖外部图片加载。

Product 字段：id、category_id、subcategory_id、i18n.zh/en.title/description、media、parameters、certifications、compliance、supplier、trade、updated_at、status。

RFQ 字段：id、product_id、buyer:{company,country,type}、quantity、target_country、expected_delivery、incoterms、message、attachments、status、created_at、reply。询盘初始不预置；由买家提交实时生成。

localStorage 使用 draft_products、rfq_drafts 和语言偏好键。询盘状态严格为 submitted → viewed → replied，查看已回复询盘不降级状态。附件保存文件名、类型和大小，明确为占位，避免提供不可用的真实下载。发布图片按受控大小保存本地预览；配额或存储失败显示可理解提示，不显示虚假成功。动态文本安全转义。

## 视觉方向

采用专业海事贸易门户：海军蓝导航、白色信息区、浅灰背景、海洋青色辅助、橙色采购及询盘主操作。首页借鉴 ECHEMI 的类目导航、搜索优先、产品陈列、快捷询盘组织方式，内容针对船舶游艇改写。品牌暂用 MARINEX / 海贸通，可集中替换。

买家页面清爽但保留采购所需信息密度，首页以海事主题视觉建立行业辨识度。供应商页面采用清晰分组的工作台，动态字段和校验提示紧邻相关控件。统一按钮、输入框、卡片、徽章、空状态与反馈弹层。中文使用系统中文字体，英文使用系统无衬线字体。

全站双语包括导航、表单、筛选、枚举、错误提示、弹层、空状态、页脚及状态。用户自行填写的说明保留原文。

## 验收与交付

在 375、768、1280 像素检查买家页面；供应商端重点检查 1280，同时确保窄屏可操作。所有表单 label 关联控件，键盘可聚焦；弹层可关闭且有明确状态反馈。

验证四类入口和参数切换、多条件筛选及 URL 恢复、排序分页、详情画廊及非法 id 空状态、涂装缺项展示与发布拦截、图片预览、草稿刷新恢复。完成一次真实浏览器内的模拟闭环：详情发起询盘 → RFQ 校验提交 → 收件箱显示 → 查看标记已读 → 回复标记已回复 → 刷新后状态保留。重复检查英文流程和空结果。

交付包括六页源代码、共享样式和 JS、内置数据和本地素材、README 启动与演示说明、验收记录。不对未经测试的浏览器或未知外部 PRD 模型作兼容性保证。
