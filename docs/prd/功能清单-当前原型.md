## 0. 一句话结论

原型已跑通「多行业发现 → 商品详情 → 买家询盘 → 供应商收件箱回复 → 买家我的询盘」的**双边闭环**，并补齐了供应商入驻、公司资料、商品发布、供应商目录、资讯/展会/线索、中英双语与响应式。

它现在已经是一个**可完整演示的业务原型**，但还不是可上线产品：没有后端、没有真实鉴权、没有文件服务、没有运营后台，也没有报价/订单。

## 2. 已实现功能清单

### 2.1 平台门户与全局导航

- 顶部：Logo、全站搜索、语言切换、主 CTA（买家显示「发布采购」、供应商显示「发布供应」）、登录/注册或账户菜单。
- 首页专属：7 项服务导航条（商品/供应商/采购需求/资讯/展会/买家入口/供应商入口）、搜索范围切换（商品/资讯/展会）、行业导航条。
- 全局页脚：品牌、6 个行业入口、按角色切换的工作台链接、语言按钮、版权。
- 账户菜单：头像、姓名/公司、角色标识、角色对应入口、退出登录。
- 搜索：全站搜索把 `q` 透传到商品列表，并保留语言参数。

### 2.2 商品发现与筛选（核心）

- 一级行业 6 个：船舶与游艇、轴承、机床、农产品、木材与林产、石化与化工。
- 专业分类 9 个，每个 3 个子类：整艇 / 配件设备 / 涂装养护 / 衍生服务 / 轴承 / 机床 / 农产品 / 林产 / 化工。
- 筛选维度：行业 → 专业分类 → 产品类型 → 类目参数（枚举多选、数值区间）→ 供应商 → 认证（CCS/ABS/DNV/ISO 9001/SGS/CE；非船舶行业为后三项）→ 关键词。
- 逻辑：不同字段之间 AND，同字段多选 OR；数值区间含边界、支持单边；搜不到时给可操作空状态。
- 排序 3 种：更新时间 / 相关度（标题精确 > 标题包含 > 全文包含打分）/ 价格升序。
- 分页每页 6 条；筛选、排序、页码全部写入 URL（`industry/category/subcategory/supplier/q/cert/p_*/min_*/max_*/sort/page/lang`），可分享、可刷新还原。
- 已选条件以 chip 展示，可单条移除；一键重置。
- 移动端：筛选面板变为抽屉（遮罩 + `inert` + 焦点陷阱 + Esc 关闭）；空状态按角色给不同 CTA（供应商→发布，其他→发采购）。

### 2.3 商品详情

- 面包屑（首页 / 行业 / 分类 / 商品）。
- 主图 + 缩略图画廊切换；中英双语标题与描述。
- 价格区间、MOQ、交期（天）、Incoterms、单位。
- 参数表按类目模板渲染，配件类额外渲染可增删的「规格键值对」。
- 认证：徽章列表 + 点击查看证书弹层（类型、编号、演示说明）。
- 涂装类专属合规面板：AFS、VOC、MSDS 链接、UN 编号、危险等级、运输限制；缺项时置顶警告；提示目的国法规（AFS/VOC）。
- 供应商卡：名称、国家、认证状态、在售数、「发起询盘」。
- 相关推荐：同类目最多 3 件，无则整块隐藏。
- 非法/缺失 `id` 走统一空状态并可返回列表。

### 2.4 供应商目录

- 从商品数据反向聚合供应商并去重，统计真实在售数与跨行业标签。
- 支持中文名/英文名/国家搜索 + 行业筛选，分页 6 条，URL 同步。
- 卡片：头像占位、名称、国家（本地化）、主营行业、认证状态、最多 3 张商品预览、在售数、「查看该供应商商品」。

### 2.5 资讯、展会与采购线索

- 3 条演示资讯、2 场展会、3 条演示采购线索（双语）。
- 列表支持关键词搜索 + 行业筛选 + 计数；详情含封面、正文段落、相关阅读、转化入口（发采购 / 进入行业）。
- 首页并排展示资讯与展会，移动端上下堆叠。
- 供应商首页显示「收到的询盘」摘要条（未读徽章 + 最近 3 条）和演示线索卡；线索详情仅供应商可进，联系按钮为演示占位。

### 2.6 账户、角色与权限（前端模拟）

- 双角色：buyer / supplier；游客可浏览，但发询盘、发布商品、进收件箱会被拦截并引导登录。
- 登录/注册：邮箱（或手机号）+ 密码；注册校验必填、邮箱格式、两次密码一致、条款勾选、供应商主营类目至少一项。
- 密码以 **SHA-256 摘要**存入 `accounts`（Web Crypto），不存明文；重复邮箱拦截。
- 演示账号：`buyer@marinex.demo` / `supplier@marinex.demo`，密码 `Demo123!`；可一键填充，首次登录自动建号。
- 登录态写 `current_user`；供应商资料同步写 `supplier_profile`；写入失败会回滚 `accounts`。
- 安全回跳：`?return=` 只接受本站 `*.html`，拒绝协议/路径穿越；已登录访问登录页会直接跳到工作台。
- 角色化 UI：主导航、账户菜单、页脚工作台、首页工作区卡片、主 CTA、询盘入口全部随身份切换；询盘页只对买家可见，发布/收件箱/公司页只对供应商可见。
- 退出登录清除 `current_user` 与 `supplier_profile`。

### 2.7 询盘闭环（买家 → 供应商 → 买家）

- **买家提交**：从商品详情带入商品上下文（改类目后自动隐藏错误上下文），或从首页快捷采购 / 通用需求进入；写入 `rfq_drafts`，状态 `submitted`，带 `buyer.id` 归属。
- **供应商接收**：收件箱统计未读与总数，按状态（submitted/viewed/replied）、日期区间、时间排序筛选。
- **已读**：打开详情自动 `submitted → viewed`，且不回退。
- **回复**：文本必填 + 附件元数据；写入 `reply{message, attachments, created_at}`，状态置 `replied`。
- **买家跟踪**：`my-rfq.html` 只展示 `buyer.id === 当前用户` 的记录；状态筛选、时间排序、详情抽屉展示完整询盘 + 供应商回复 + 回复时间；未回复显示「等待供应商回复」。
- **同步**：同一浏览器多标签通过 `storage` 事件实时刷新；页面重新聚焦也刷新；首页供应商摘要条同步未读。
- **数据校验**：读取时校验字段类型、状态枚举、数量、时间、附件结构；损坏数据不覆盖、不误报保存成功。

### 2.8 供应商发布与商品管理

- 仅供应商可进；访问他人草稿会被拒绝并提示切换账号。
- 表单顺序：基本信息 → 供应商信息 → 技术参数 → 认证 → 贸易信息，配滚动联动的步骤导航。
- 类目驱动：切换行业/分类后，参数字段模板即时重渲染（涂装切到合规组、配件显示规格行）。
- 基本信息：中英标题、中英描述、主图/多图（最多 4 张、每张 ≤1MB、转 Data URL 本地预览）、封面标识、单张删除。
- 供应商信息：公司中英名、国家、联系人、邮箱、城市、电话、官网、中英简介；已注册供应商自动回填并显示「正在以 XX 身份发布」，可直接跳公司资料。
- 认证：可增删多行（类型 + 编号 + 证书文件名），编号必填。
- 贸易：MOQ、交期、价格区间（校验 max ≥ min）、单位、Incoterms、币种固定 USD。
- 校验：必填项、数字有效性、日期合法性、涂装 6 项合规强制（AFS/VOC/MSDS/UN/危险等级/运输限制）、供应商资料完整性。
- 保存：草稿（`draft`）与提交（`published`）都写 `draft_products`；提交后已上架商品进入买家列表与详情；`?draft=` 可继续编辑；有未保存改动时离开页面会提示。
- 我的商品：只列本人草稿与已提交，状态徽章 + 继续编辑 + 空状态。

### 2.9 公司资料与资质

- 展示：公司中英文名、审核徽章（pending / verified / rejected）、国家、城市、官网、业务类型、成立年份、员工规模、联系人、职位、邮箱、电话、主营行业、中英简介、认证列表、公司实拍。
- 编辑：字段可改；认证可增删并预览证书图；实拍可多选预览（只记文件名）；保存写回 `supplier_profile` 与 `accounts`，并同步 `current_user` 公司名。
- 「模拟审核通过」按钮可把状态切到 `verified`（演示用）。
- 存储损坏或非供应商身份有独立提示与引导。

### 2.10 双语、响应式与可访问性

- 中英双语集中字典（约 437 个文案键）；正文、按钮、枚举、状态、错误、空状态、aria-label、图片 alt 均随语言切换；默认英文，偏好写 `marine_lang`，支持 `?lang=zh`。
- 语言切换保留当前筛选条件、表单内容与页面参数。
- 响应式：375 / 768 / 1280 三档，样式表 38 个媒体查询；移动端折叠导航、筛选抽屉、工作区上下堆叠。
- 可访问性：跳转到主内容链接、表单 label 关联、`aria-invalid`、`aria-live` 结果计数/轮播播报、`focus-visible`、`prefers-reduced-motion`、键盘轮播（方向键/Home/End/空格）、弹层 Esc 关闭、焦点陷阱。
- 表单增强：文件选择器与日期控件本地化（自绘日历、键盘方向键选日、今天/清除）。

### 2.11 数据与存储

| 存储键 | 用途 |
| --- | --- |
| `accounts` | 模拟账户（含 SHA-256 密码摘要、角色、企业信息、审核状态） |
| `current_user` | 当前登录态（id/role/name/company） |

## 3. 现在就能完整演示的流程

1. **中英切换 + 多行业浏览**：首页切中文 → 点「机床」→ 看到该类目空状态 → 走 CTA 发采购。
2. **精准筛选**：船舶 → 整艇 → 材质 FRP + 认证 CCS + 长度 12–13 → 排序/翻页 → 复制 URL 重开，条件与结果一致。
3. **商品决策**：打开涂装 p09 看 MSDS/UN/危险等级；打开 p12 看缺项警告；点认证徽章看证书；点缩略图换主图。
4. **双边询盘闭环**：`buyer@marinex.demo` 提交询盘 → 查看「我的询盘」（已发送）→ 切 `supplier@marinex.demo` → 收件箱打开（变已读）→ 回复 → 切回买家 → 状态「已回复」+ 回复内容。
5. **供给侧**：供应商登录 → 发布商品（选涂装、故意漏 MSDS/UN 被拦截 → 补齐提交）→ 我的商品 → 买家列表出现该商品。
6. **企业资料**：公司页编辑资料、加认证、传实拍预览、模拟审核通过 → 发布页自动回填公司信息。

## 4. 当前做不到 / 明确边界

| 能力 | 现状 | 影响 |
| --- | --- | --- |
| 后端与接口 | 完全没有，全部 localStorage | 数据不跨设备、不跨浏览器；无法多人协作演示 |
| 真实鉴权 | 前端模拟；密码仅 SHA-256（无盐、无服务端） | 可被绕过，不能作为安全方案 |
| 文件与附件 | 商品图存 Data URL；证书/实拍/附件只存文件名或元数据 | 无法真实上传、下载、预览附件 |
| 通知 | 无邮件/站内信 | 「供应商将收到通知」仅为文案 |
| 运营后台 | 无企业审核台、商品审核、需求管理、投诉处理 | 审核只能靠「模拟通过」按钮 |
| 多卖家隔离 | 收件箱读取全部 `rfq_drafts`，不按供应商过滤 | 多供应商场景下会互相看到询盘 |
| 会话模型 | 单条 `reply` 对象，再次回复覆盖上一条 | 无法多轮沟通、无报价版本 |
| 报价/订单/支付/物流 | 无 | 闭环止于「回复」，不进入交易 |
| 买家工作台 | 只有「我的询盘」 | 无收藏、对比、消息、企业资料、采购历史 |
| 商品管理 | 只有列表 + 编辑 | 无上下架、删除、批量、审核状态、数据统计 |
| 目标市场字段 | 详情页会展示 `target_country`，但询盘表单未采集 | 我的询盘/收件箱中该字段显示「—」 |
| 多币种 | 币种固定 USD，价格符号写死 `$` | 非美元报价无法表达 |
| 数据规模 | 仅船舶 16 件商品，其余 5 行业为空 | 只能演示单行业真实感 |
| 运行方式 | `file://` 未做浏览器实测 | 建议统一用本地 HTTP，localStorage 共享更稳 |
| 首页遗留代码 | 账户逻辑里仍有旧版 `hero-copy`/`quote-banner` 兜底选择器 | 当前首页无对应节点，不影响功能，属可清理项 |
| 深色模式 / 旧浏览器 | 未实现 / 不支持 | — |
