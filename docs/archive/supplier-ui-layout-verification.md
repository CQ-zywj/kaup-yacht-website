# 供应商界面布局核查

日期：2026-10-21。以本地前端为准，不部署或推送。本次修复延续现有配色与页面结构。

## 修复

- 素材库原来的 select、文本框、文件选择器实际高度为44/46/56px。统一成48px，并使用明确的四列上传网格，窄屏逐列排列。
- 文件选择器的文件名采用单行省略，完整文件名保留在悬停提示中；选择按钮保留44px点击高度。
- 素材图片限定在4:3区域内，图片不再越界覆盖文件名；文件名和元信息在独立白底区显示。
- 认证、关联产品、素材详情、客户详情、素材选择器等弹窗增加内边距、宽度限制和视口内滚动，避免表单贴边、日期框过窄。
- 统一工作台标题与公司状态区的间距，侧栏标题改为「供应商工作台」，避免重复「店铺总览」。
- 内容中心筛选器在桌面并排、手机堆叠；内容编辑封面区改为明确网格。
- 手机工作台导航采用局部横向滚动；客户卡片在窄屏按一列展示；店铺头部按钮允许换行。
- 公司完善度条、团队编辑字段、证书卡片长文案和附件链接均检查换行。
- 更新误导性的上传说明及认证空状态，补齐工作台商品表头的双语文案。
- 统一静态资源版本为 `ui20261021d`，避免浏览器混用旧页面脚本与新样式。

## 页面范围

店铺总览、素材库、认证与资质、内容中心、公司信息、店铺装修、财务中心、客户管理、批量导入、我的商品、店铺主页、公司公开页，共12页。

## 检查方式与结果

使用真实浏览器逐页截图并检查DOM边界。中文在桌面及375/390/768/1024px检查，英文在390/1298px检查。未发现页面横向溢出或表单超出页面边界。导航条的局部横向滚动属于预期行为。

另检查认证上传弹窗、公司编辑表单、内容编辑器，覆盖桌面与手机。素材库四个控件的上下边界一致、实际高度均为48px；素材图片不超出自己的图片区。

实际选择长中文文件名的测试图片后，附件选择器仍为48px，文件名省略显示，完整名称保留在title提示中。空表单产生6处错误提示时，900px认证弹窗的scrollWidth与clientWidth一致，没有横向溢出。测试未保存到商家资料。

逻辑回归沿用 `node --test tests/*.test.cjs`，上传与买卖家展示联动沿用 `tests/browser-supplier-flow.cjs`。

结果：64项自动化测试通过；浏览器上传联动验收通过；新增12页的中英文及多宽度检查通过。以上为本地验收，不代表跨设备数据共享能力。
