## 数据层替换影响

| 现有调用方 | 当前依赖 | 升级需保留 |
| --- | --- | --- |
| home.js、products.js、product.js | 同步 U.products/U.product | 首页精选、筛选排序分页、详情、同类推荐和空状态 |
| publish.js、supplier.js | draft_products | 草稿恢复、图片预览、证书文件名、涂装校验和继续编辑 |
| rfq.js、inbox.js | rfq_drafts | 商品上下文、提交校验、附件元数据、刷新与跨标签同步 |
| core.js、core.test.cjs | 单 reply 与 submitted/viewed/replied | 旧数据转换后保留原回复和时间；新消息不能覆盖历史 |
| common.js、common.test.cjs | 同步存储与错误提示 | 读取失败禁止覆盖，写入失败不得显示成功 |
| static.test.cjs | 固定七页清单、JSON 与 JS 数据一致 | 扩展页面清单并保留本地资源和中英完整性检查 |

旧浏览器运行验收见 verification.md，不能视为第二版新功能的验收证据。第二版实施后须重新运行受影响的旧流程，并新增多企业隔离、多轮会话、独立报价、迁移幂等和异步错误验证。
