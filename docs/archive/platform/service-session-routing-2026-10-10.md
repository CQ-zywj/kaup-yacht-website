# 服务入口跟随登录身份

根因：首页服务入口固定指向身份登录页，登录页也没有同身份会话判断。

公开页面的服务入口在上下文刷新时跟随身份：已登录供应商进入 `supplier.html`，已登录买家进入 `my-rfq.html`；访客和不同身份继续进入对应登录页。直接打开同身份登录、注册页时，自动进入工作台，避免重复认证。携带安全的 return 参数时保留返回目标，拒绝外部 URL 和认证页自跳转循环。

验证：新增角色匹配及安全返回测试，60 项测试通过。浏览器验证已登录供应商从首页服务入口进入工作台；直接访问供应商登录页后 URL 自动切换为工作台且不存在登录表单。演示会话仍保留供应商身份。
