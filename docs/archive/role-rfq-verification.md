# 2026-10-09 身份展示与采购表单调整

买家、供应商和未登录状态统一使用 MarineAccounts.permissions。

- 买家页头为“发布采购”，不显示我的商品、供应发布、公司资料、供应商询盘收件箱。页脚为买家采购入口。
- 买家直接打开 publish、supplier、company、inbox 页面只显示身份提示及采购/切换账号入口，不初始化编辑、发布或回复逻辑。
- 供应商页头、首页操作和页脚显示发布供应、商品及企业资料管理、询盘收件箱；不显示采购操作。公共产品浏览保持可用。
- 登录、退出、语言切换及跨标签页账号变更同步身份展示。
- 询盘新增 category_id + subcategory_id 联动必填选择；删除 target_country 输入与新记录字段；expected_delivery 非必填。
- 商品询盘默认回填产品分类；修改为另一分类后取消原商品关联，避免分类与 product_id 冲突。
- 新采购记录不依赖目标市场字段，旧记录继续兼容。供应商详情展示类目、子类目，空交期显示“—”。买家成功提交后可返回产品列表。

验证：39 项 Node 测试通过；新增权限策略和无目标市场/交期记录测试先失败再通过。
实际浏览器验证买家首页无可见供应商操作、四个供应商页面均限制；供应商首页和工作台可用；未填交期成功提交且供应商详情正确展示分类；商品分类回填及类目变更联动正常；错误日志为空。

这是静态原型的前端身份控制，真实后端接入时必须由服务端校验权限。现阶段登录和询盘仍是本地演示。
